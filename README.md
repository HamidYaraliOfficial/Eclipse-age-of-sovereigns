## English

ECLIPSE is a browser-based 3D grand-strategy game foundation built with Three.js and Vite. This playable version includes an interactive hex map, four fictional nations, nine city sites, turn-based economy, six building types, starter research, diplomacy, infantry recruitment, a tactical 3D battle view, world events, and save/load. The interface supports English, Persian (RTL), and Simplified Chinese.

### Run it

Requires Node.js 20.19+ and npm. Extract the ZIP, open a terminal in this folder and run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://127.0.0.1:5173`. Run `npm test` for the built-in engine test suite and `npm run build` to create a production build. On Windows you can also double-click `run-game.bat`.

### Project scope

This is a playable foundation, not a claim that every feature of the original AAA-scale concept is finished. Multiplayer, the full 40+ nation / 150+ city world, a curated 200-node technology tree, advanced logistics and a full campaign are roadmap items. See [README.en.md](README.en.md) and [GAME_DESIGN.md](GAME_DESIGN.md).

## 简体中文

ECLIPSE 是使用 Three.js 和 Vite 构建、可在浏览器中运行的 3D 大战略游戏基础版本。当前可玩版本包含可旋转的六边形地图、四个虚构国家、九个城市位置、回合制经济、六种建筑、入门科技研究、外交、步兵招募、3D 战术战斗场景、世界事件以及存档/读档。界面支持英语、波斯语（从右向左）和简体中文。

### 运行方式

需要 Node.js 20.19 或更高版本以及 npm。解压 ZIP，在项目文件夹打开终端并运行：

```bash
npm install
npm run dev
```

打开 Vite 显示的本地地址，通常是 `http://127.0.0.1:5173`。运行 `npm test` 可执行内置游戏逻辑测试；运行 `npm run build` 可构建生产版本。Windows 用户也可以双击 `run-game.bat`。

### 当前范围

这是可玩的基础版本，并不表示原始 AAA 规模设计中的所有功能均已完成。多人模式、40 多个国家和 150 多个城市的完整世界、经过完整设计的 200 节点科技树、高级后勤和完整战役仍属于后续开发计划。详情请见 [README.zh-CN.md](README.zh-CN.md) 和 [GAME_DESIGN.md](GAME_DESIGN.md)。
