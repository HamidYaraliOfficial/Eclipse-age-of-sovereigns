# ECLIPSE: AGE OF SOVEREIGNS — عصر فرمانروایان

**سازنده: حمید یارعلی**  
**حق نشر © ۲۰۲۶ حمید یارعلی. تمامی حقوق محفوظ است.**

ECLIPSE یک پایهٔ قابل‌بازی برای یک بازی راهبردی سه‌بعدی تحت مرورگر است که با Three.js و Vite ساخته شده است. این نسخه شامل نقشهٔ شش‌ضلعی سه‌بعدی با دوربین قابل چرخش، چهار کشور خیالی، نه موقعیت شهری، ساخت‌وساز، شبیه‌سازی منابع در نوبت‌ها، پژوهش، دیپلماسی، جذب نیرو، تصمیم‌های تاکتیکی نبرد، رویدادها و ذخیره/بارگذاری است.

## پیش‌نیازها

- Node.js نسخهٔ ۲۰٫۱۹ یا جدیدتر (نسخهٔ ۲۲ LTS پیشنهاد می‌شود)
- npm
- مرورگر جدید با پشتیبانی فعال از WebGL

## نصب و اجرا

```bash
npm install
npm run dev
```

آدرسی را که Vite نمایش می‌دهد در مرورگر باز کن؛ معمولاً `http://127.0.0.1:5173` است. فایل `index.html` را مستقیماً باز نکن، چون importهای ماژولی به وب‌سرور محلی نیاز دارند.

## آزمون و ساخت نسخهٔ نهایی وب

```bash
npm test
npm run build
npm run preview
```

## راهنمای بازی

- برای چرخاندن نقشه، آن را با ماوس بکش؛ برای بزرگ‌نمایی از چرخ ماوس یا دکمه‌های `+` و `−` استفاده کن.
- برای دیدن اطلاعات زمین، روی یک خانهٔ خشکی کلیک کن.
- یک شهر تحت کنترل آورلیا را انتخاب کن و از بخش «ساخت‌وساز» ساختمان بساز.
- از بخش «پژوهش» یک فناوری را آغاز کن؛ پیشرفت در هر نوبت افزایش می‌یابد.
- با اعزام فرستاده، پیمان تجاری یا اتحاد، روابط را مدیریت کن.
- پیش از آغاز نبرد، نیروی پیاده جذب کن. در حالت نبرد می‌توانی پیشروی، حفظ موضع، حملهٔ جناحی، توپخانه یا عقب‌نشینی را انتخاب کنی.
- آیکون ذخیره، بازی را در حافظهٔ محلی مرورگر نگه می‌دارد. برای تهیهٔ فایل مستقل، «خروجی ذخیره» را بزن و با «ورود ذخیره» آن را بازیابی کن.

## محدودهٔ نسخه

این نسخه یک پایهٔ قابل‌بازی است و به‌عنوان بازی AAA کامل معرفی نمی‌شود. چندنفره، محتوای کامل کارزار، شبیه‌سازی ۴۰ کشور و درخت پژوهش حرفه‌ای ۲۰۰ گره‌ای هنوز پیاده‌سازی نشده‌اند.
