# ECLIPSE: AGE OF SOVEREIGNS

**Creator: Hamid Yareli**  
**Copyright © 2026 Hamid Yareli. All rights reserved.**

ECLIPSE is an original browser-based 3D grand-strategy game foundation built using Three.js and Vite. This playable build includes a rotatable 3D hex map, four fictional nations, nine city sites, construction, turn-based resource simulation, a starter research tree, diplomacy, army recruitment, tactical battle decisions, events and save/load.

## Requirements

- Node.js 20.19+ (Node.js 22 LTS recommended)
- npm
- A modern browser with WebGL enabled

## Installation

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, normally `http://127.0.0.1:5173`.

## Checks

```bash
npm test
npm run build
npm run preview
```

## Controls

- Drag the map to rotate; scroll or use `+` / `−` to zoom.
- Click a land hex to inspect it.
- Select an Aurelian city to build structures.
- Start research and advance turns to progress it.
- Improve relations, establish trade pacts or alliances, recruit infantry, and open a tactical battle against a rival.
- The save icon stores the game in browser local storage. Use **Export save** and **Import save** for JSON files.

## Scope

This is a tested playable foundation, not a claim of a finished AAA release. Multiplayer, full campaign content, a complete 40-country simulation and a polished 200-node research tree are not implemented in this version.
