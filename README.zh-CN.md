# ECLIPSE: AGE OF SOVEREIGNS — 主权时代

**创作者：Hamid Yareli（哈米德·亚雷利）**  
**版权所有 © 2026 Hamid Yareli。保留所有权利。**

ECLIPSE 是一款使用 Three.js 和 Vite 构建、可在浏览器中运行的 3D 大战略游戏可玩基础版本。当前版本包含可旋转的 3D 六边形地图、四个虚构国家、九个城市位置、城市建设、回合制资源模拟、入门科技研究、外交、步兵招募、战术战斗决策、动态事件以及存档/读档。

## 环境要求

- Node.js 20.19 或更高版本（推荐 Node.js 22 LTS）
- npm
- 启用 WebGL 的现代浏览器

## 安装与运行

```bash
npm install
npm run dev
```

打开 Vite 在终端中显示的本地地址，通常为 `http://127.0.0.1:5173`。不要直接双击打开 `index.html`，因为 ES 模块需要本地 Web 服务器。

## 测试与构建

```bash
npm test
npm run build
npm run preview
```

## 操作说明

- 拖动地图以旋转；滚动鼠标滚轮或点击 `+` / `−` 缩放。
- 点击陆地六边形查看地形、控制方、城市和建筑。
- 选择奥瑞利亚控制的城市以建造设施。
- 在科研页面启动科技研究，结束回合可推进研究进度。
- 派遣使节、签署贸易协定或提出结盟。
- 招募步兵后，可对竞争国家发起战术战斗，并选择推进、坚守、侧翼机动、炮火打击或撤退。
- 顶部保存按钮将存档保存在浏览器本地；也可导出 JSON 存档文件，再通过导入功能恢复。

## 当前版本范围

这是一个经过自动化测试的可玩基础版本，并非已完成的 AAA 商业大作。多人模式、完整战役内容、完整的 40 国模拟以及经过完整设计的 200 节点科技树尚未实现。
